# The Arcades History

This is an Alpha home for small, source-backed history projects at [history.thearcades.me](https://history.thearcades.me/).

Alpha means the projects are incomplete by design. Claims are assembled from recorded sources, uncertainty is preserved, and proposed corrections are reviewed before maintainers change the corpus. The public `Dispute this` links prepare a GitHub issue for a contributor to review and submit; they do not change the record automatically.

## Projects

- [Furry History Board](https://history.thearcades.me/furry) — print, conventions, online communities, people, and a sourced literary-awards pilot.
- Cultural Weather Vane — music and news mapped together as cultural atmosphere.

## Development

```bash
npm install
npm run typecheck
npm test
npm run build
```

The canonical dataset and its evidence contracts live under `projects/furry/src/data`. Please keep names, claims, source URLs, confidence, and explicit unknowns unchanged unless a reviewed correction is being made.
